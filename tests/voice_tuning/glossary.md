# 用語の言いかえ表 (glossary.md v1.0.0 2026-11-15 JST)
文書では、左の語を初出で右のように言いかえるか、括弧で注釈する。2回目以降は、言いかえた語に統一する。

| 専門用語 | 言いかえ・注釈 |
|---|---|
| モーラ | 「拍」。かな1文字ぶんの長さ(「きゃ」は1拍、「ー」「ッ」も1拍) |
| F0(基本周波数) | 「声の高さ(Hz)」。数字が大きいほど高い声 |
| アクセント核 | 「声が下がる位置」(「は'し」の `'` の位置) |
| 抑揚 / イントネーション | 声の上がり下がりの形 |
| 同期再生(ブロッキング) | 「話し終わるまで、次の行へ進まない」 |
| バッファ | 「音を作って一時的に置いておく場所(メモリ)」 |
| PSRAM | 「ESP32-S3 に付いている追加メモリ」 |
| 素片連結 / PSOLA | 「録音した音の断片をつなぎ、高さと長さを変える方式」。細部は説明しない |
| 辞書 | 「声のもとになる、音の断片のセット」 |
| 音色(声質) | 「その人らしい声の響き。この方式では変えられない」 |
| g2p | 「漢字かな交じり文を、かなに直すツール」 |
| 頭打ち / クランプ | 「それ以上は上がらない」 |
| 実効値(RMS) | 「平均的な音の大きさ」 |
| I2S / DMA | 初心者向け本文には出さない。必要なら docs/ARCHITECTURE.md へ誘導 |
