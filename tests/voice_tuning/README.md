# 声の調整サンプルをPCで再生成する

付録です。Arduino IDEでライブラリを使うためにPythonやコンパイラーを入れる必要はありません。
作者：まこと／音声素材：VOICEVOX:ずんだもん。[音声の条件](../../docs/VOICE_AND_CREDITS.md)を確認してください。

既存のPython ziglang環境から、リポジトリ直下で実行します。

```sh
python tests/voice_tuning/run_render.py
```

既存のAPI回帰試験を実行し、そのPC用の代用品を使って実ライブラリと実辞書をコンパイルします。
`render.cpp`と`cases.txt`は提供パックの内容です。`run_render.py`が失敗・欠落した出力を検出します。
13本のWAVと実行ログ、配布WAVとのSHA256一致結果を、Git対象外の`.test-output/`内の新しいフォルダーへ保存します。
配布WAVは上書きしません。コンパイラー等の違いで不一致になる可能性はありますが、不一致を成功にはしません。

## 今回の再生成確認

2026-11-15のWindows上の再生成では、全サンプルの生成に成功し、音のフレーム数も一致しましたが、ファイル全体のSHA256一致確認は不合格でした。
配布WAVには再生成プログラムが出力しない`C2PA`追加区画があり、音声データ自体にも一部に小さな差がありました。原因は断定していません。
このため、同じ環境で上のコマンドを実行した場合も、厳密な一致確認は失敗として終了する可能性があります。
提供されたWAVは追加区画を含めそのまま保持し、違いを隠すための書き換えや比較条件の緩和は行っていません。
既存APIの回帰試験の合否と、この厳密な一致確認の合否は別です。実機の聞こえ方を確認したことにもなりません。

この処理は実機・シリアルに接続しません。音声の高さの再推定は行いません。
配布された`measured.csv`の高さはpyworld harvestで推定された値で、最大値には推定誤差を含みます。

`facts.json`は提供された仕様・実測・未確認事項、`glossary.md`は用語の言いかえ表です。
初期化後の速さ・高さ・音量はスケッチで明示し、既定値の推測に依存しません。
