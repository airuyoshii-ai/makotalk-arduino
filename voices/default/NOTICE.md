# 音声 default の著作・利用条件

- 文書版：2.1（2026-11-10 JST）
- 対象：`src/voices/default/voice_image.h`（著作情報付き辞書 MKTV v3）の PCM と、それを用いて MakoTalk が生成する音声
- 規約確認日：2026-11-10（下記の要点はその時点の控え。正式な条件は常に公式ページ）

## クレジット

**VOICEVOX:ずんだもん**

音声素材は、VOICEVOX のずんだもん（ノーマル・スタイルID3）で生成した音声から切り出した
123素片です。権利者は SSS合同会社（東北ずん子・ずんだもんプロジェクト）です。
MakoTalk のコードに付くライセンスは、この音声には適用されません。

## MakoTalk での表示・告知

この音声を使うアプリケーションは、次を満たします。

| 時点 | 内容 |
|---|---|
| 辞書の初回使用時（Flash 消去後・辞書差し替え後） | エンジンが「この音声は、ボイスボックスのずんだもんを使用しています。」と発話（以後は告知済みフラグにより省略） |
| 起動時（毎回） | 著作情報をアプリへ通知。画面に `VOICEVOX:ずんだもん` を表示（任意・推奨）。画面のない機器はシリアル出力と README に記載 |
| 著作ページ | 本書へのリンクを README の音声クレジット欄に掲載 |

表示文・発話文は `voices/default/voice_meta.json` が正本です。
辞書生成時に先頭区画へ書き込まれ、辞書と一体で配布されます。
エンジンは著作情報を検査できない辞書を起動しません。

## 利用者が守る条件（第三者へ引き継ぐこと）

1. クレジット `VOICEVOX:ずんだもん` を、利用者が少し探せば分かる場所（紹介画面・説明文・
   動画の概要欄など）に記載すること。
2. 次の利用をしないこと（音源の共通規約の禁止事項の要点）。
   - 公序良俗に反する利用
   - 政治活動・宗教活動、またはそれにつながる利用。特定の個人・団体（国家を含む）を
     非難・批判・応援する目的の利用
   - 情報商材での利用、または情報商材の宣伝目的の利用
   - 意図的な虚偽や誤解を招く内容の作成・共有・拡散を目的とした利用
   - 風俗営業（接待飲食等）・性風俗関連特殊営業に当たる業態での利用
   - 反社会的勢力の利用・関与・協力、暴力的要求・脅迫・信用毀損・業務妨害を伴う利用
3. **本プロジェクトの配布方針：音声辞書（`src/voices/default/voice_image.h` とその PCM）を MakoTalk から切り離し、
   単体の音声素材として配布・販売しないこと。** MakoTalk に組み込んだ形での利用に限る。これは公式規約の同文条項ではなく、本プロジェクト側の配布方針。
4. 生成した音声の利用を他者に許諾する場合は、その相手にも公式音源規約とVOICEVOX規約に従うことを
   義務付けること。
5. クレジットを表示せずに商用利用する場合は、権利者との個別契約が必要（公式規約に記載）。
