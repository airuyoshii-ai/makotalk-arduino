# 発話APIと台詞

`#include <MakoTalk.h>`でAPIを読み込み、`#include <MakoTalkVoiceDefault.h>`で既定辞書を選びます。

| API | 動作 |
|---|---|
| `mbegin(voice, bclk, lrclk, data, port=I2S_NUM_1, seconds=8)` | MKTV v3検査・作業領域確保・I2S設定・初回告知 |
| `mspeak("あいうえお")` | かなを合成し、完了まで待つ。成功時true |
| `mlastError()` | 直前の失敗理由 |
| `msetSpeed(130)` | 40〜300。100が基準。実時間の倍率は子音長等にも依存 |
| `msetPitch(100)` | 40〜250。100が基準 |
| `msetVolume(70)` | 合成音量0〜100。I2S出力には別途減衰上限を適用 |
| `mannounceCredit()` | 選択中の辞書のクレジットを手動発話 |
| `mend()` | I2S・作業領域を解放 |

`mbegin`と発話関数のboolを確認してください。失敗時に無限ループや再起動を自動では行いません。
初期化バッファは8〜30秒の指定です。標準8秒のfloat作業領域＋PCMだけで約768KB使うため、PSRAMが必要です。
長文は分割してください。発話が容量を超えた場合、部分的な音声を出さずエラーにします。

## 入力

ひらがなをカタカナへ正規化します。漢字変換や読み推定ではありません。
助詞「は」「へ」を「わ」「え」へ直す処理や、アクセント辞書による自動推定はありません。
音を意図した読みで指定してください。

| 入力 | 扱い |
|---|---|
| `あいうえお` / `アイウエオ` | 同じかな列 |
| `こんにちは` | 文字どおりのかな。助詞等の自動読み替えなし |
| `さんじゅうに` | 数字の読みとして指定可能 |
| `32` / `ESP32` / `今日は` | 自動読みは未対応。エラー |
| `ー` | 長音。例：`ふーー` |
| `っ` / `ッ` | 促音 |
| `、` / `。` / `,` / `.` | 長い休止 |
| 空白・改行・`_` | 短い休止 |
| `'` | 直前のモーラをアクセント核として指定 |
| `?` / `!` | 疑問・感嘆調の記号 |

辞書がその音を収録している必要があります。未収録音、不正UTF-8、漢字・英数字等、192モーラを超える文は拒否します。
これらを黙って読み飛ばして成功扱いにはしません。小書き文字や結合文字も、正規化・辞書で扱えない形はエラーになります。

```cpp
msetSpeed(130);
if (!mspeak("やったー! うれしいね!")) {
  Serial.println(mlastError());
}
```

## 出力と利用上の制約

16kHz・16bit PCMを左右同値でI2Sへ出します。波形ごとにピーク12288・20ms区間RMS5000を上限として減衰します。
これは音圧・アンプ出力電力の校正値ではありません。音量設定を上げても、この減衰上限は維持されます。

標準APIは1つの既定インスタンスです。並行呼び出し・割り込みからの利用は非対応です。
低水準エンジンは共有作業状態を持つため、複数インスタンスの同時使用も想定していません。
I2Sポートがアプリ内の別機能で使用中の場合は、空いている対応ポートを選んでください。
