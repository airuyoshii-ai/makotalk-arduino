# 確認範囲

## 最新版

2026-11-10、権利者からArduinoライブラリ版の動作確認済みという報告を受領しました。
本版は動作確認済みArduinoライブラリ2.1.0を基準とします。古い音声なし版や26秒専用スケッチとは区別しています。
音声辞書・ソースのハッシュにより、確認済みライブラリから文書・配布メタデータ以外を変更していないことを照合します。

| 項目 | 結果・根拠 |
|---|---|
| ボード | ESP32-S3、Quad Flash16MB、Octal PSRAM8MB |
| Arduinoパッケージ | esp32 3.3.12 |
| 最小例のビルド | 成功。Flash1,559,611B、静的RAM26,780B |
| 実機発話 | 権利者から2026-11-10に確認済みと報告 |
| PC回帰試験 | 実ライブラリ・実辞書、I2S/NVSを模擬して合格 |
| 音声データ | 従来PCMと一致。今回の整備で変更なし |
| 再起動設定の問題 | Octal Flash設定の不一致を診断し、READMEへ注意事項を追加 |

PC試験は、ひらがな／カタカナのPCM一致、未収録音・不正UTF-8等の拒否、過長文を出力前に拒否、
エラー回復、左右同値・ピーク上限、CRC異常拒否、初回告知・次回省略、出力失敗時の未記録を確認しています。
assertを有効にして実行します。

## 未確認・対象外

- あらゆるESP32製品・RP系・UNO/Nano等での動作。
- 任意の漢字文章の読み、STT、LLM、ニューラル感情TTS。
- 校正された音圧・スピーカー特性、一般的な音声品質の保証。
- カメラによる口パクの同期精度測定。
- 今回の最小例に対する個別のNVS試験結果を、過去の別デモの結果と同一視すること。

## 任意のPC試験

既存のPython ziglang環境で、次を実行できます。

```sh
python tests/run_api_regression.py
```

コンパイラ・テスト実行環境は別途必要です。Arduino IDEでの利用にPythonは不要です。
試験結果は`.test-output/`へ保存し、Git管理から除外します。ハードやシリアルへ接続しません。
